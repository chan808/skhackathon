# 서류 합격 공지와 1차 상세 응시 안내 확인

2026년 10월 14일 KST 기준. **서류 합격 안내를 받았다면 상세 응시 메일을 확보하고 실제 연습을 시작한다.** 상세 메일을 기다리는 동안에도 AI 개념과 자료 해석·검증 연습은 진행할 수 있다. 다만 응시 시각·접속 방법·감독·허용 도구는 추측해서 결정하지 않는다.

아래 내용은 공식 공지와 일반 응시자 안내를 정리한 것이다. 개인 메일함의 발송·수신 이력은 확인하지 않았다. 개인 상태·진도·식별 정보는 공개 자료에 포함하지 않는다.

초대 메일을 받은 뒤에는 아래 검색 절차보다 초대별 날짜·시각·문항 수·시간·접속 경로를 확인한다. 20문항·30분과 16문항·90분 구성에는 [두 세션 학습 전략](09-first-round-time-strategy.md)을 적용하되 영역명과 허용 도구는 별도 안내에서 확인한다.

## 공식 사이트에서 확인한 합격 공지

기존 로그인 상태의 공식 대회 공지 화면에서 다음 안내를 읽었다. 새 로그인이나 실제 시험 접속은 수행하지 않았다. 이름·계정 식별 정보·접속 토큰은 저장하지 않았다. 링크는 계정에 따라 접근이 제한될 수 있다. [공식 대회 공지](https://skhynix-hackathon.com/my/notice)

|---|---|
| 공지 날짜 | 2026년 10월 10일 |
| 제목 | SK하이닉스 AI 해커톤 2026 서류 전형 합격 및 1차 예선 안내 |
| 합격 | 서류 전형 합격 안내 |
| 1차 | 10월 17~18일 중 하루, 온라인 |

| 배정 변경 | 지정 응시일 변경 어려움 |
| 상세 메일 | 날짜·링크·환경·유의사항 별도 안내 |

10월 14일에 확인한 화면도 위 내용이었다. 이 공지는 합격과 상세 메일 발송 계획의 근거이지, 실제 메일 발송 완료·수신 완료·메일 인증 결과의 증거는 아니다. 확인한 공지에는 개인별 시작 시각, 총시간, 문항 구성, 외부 도구 허용표가 없다. [공식 공지 화면](https://skhynix-hackathon.com/my/notice)

공개 예선 FAQ도 다시 확인했다. 1차는 기본 소양·활용, 2차는 데이터 기반 문제 해결을 다루며 AI로 문제를 정의·해결하는 과정을 강조한다. 구체적인 시간·문항·도구 설정은 추가되지 않았다. [대회 예선 FAQ](https://skhynix-hackathon.com/ai-2026)

## 상세 메일을 찾는 순서

아래 검색은 본인이 등록한 메일 계정에서 수행한다. 이 폴더에 개인 주소나 메시지 원문을 저장할 필요는 없다.

1. 대회 지원 때 등록한 계정과 현재 보는 메일 계정이 같은지 확인한다.
2. 받은편지함뿐 아니라 전체메일·스팸·프로모션·정크·보관·삭제함을 확인한다.
3. 먼저 `notice@skhynix-hackathon.com` 또는 `skhynix-hackathon.com`으로 발신자를 검색한다.
4. 제목·본문에서 `SK하이닉스`, `AI 해커톤`, `1차 예선`, `응시 안내`, `프로그래머스`, `초대`를 각각 검색한다. 검색 기간은 합격 안내 전후부터 현재까지로 둔다.
5. 플랫폼 발신자 검색도 추가한다. 일반 프로그래머스 가이드는 초대 메일 발신자로 `no-reply@monito.io`, `no-reply@programmers.co.kr`를 안내한다. 이번 SK 대회의 실제 발신 주소라고 확정한 것은 아니다.
6. 여러 안내가 있으면 최신 초대와 변경 안내를 우선하고, 여전히 없으면 운영사에 발송 여부·등록 계정·재발송을 확인한다.

일반 응시자 가이드도 등록 계정·스팸/프로모션 확인 후 미수신이면 주최 측에 재발송을 요청하라고 설명한다. 예정일을 이미 지나 상세 안내를 못 찾았다면 시험 당일까지 기다리는 것보다 오늘 확인 요청을 준비하는 편이 낫다. [프로그래머스 공식 접속·초대 가이드](https://user-guide.grepp.co/en/articles/Accessing-the-Test-Page-5dff571a)

이는 메일 발송 실패나 운영사 지연을 확정한 판단이 아니다. 현재 필요한 것은 상세 메일의 위치와 발송 여부를 확인하는 일이다. 오래된 초대, 유사 대회의 공지, 다른 계정에 온 메시지를 이번 시험 정보와 섞지 않는다.

## 아직 확인할 실전 조건

| 항목 | 상세 안내에서 확인할 내용 |
|---|---|
| 일정 | 본인 배정일, 입장 시작·마감, 시험 시작·종료 |
| 접속 | 최신 초대·접속 코드, 인증 방식, 문제 화면 진입 순서 |
| 형식 | 영역별 문항과 답안 형식, 문제 재방문·저장 방법 |
| AI | 제공 어시스트, 질문·자료 제한, 기다리는 시간 |
| 외부 도구 | 검색·외부 AI·코드·계산기·메모 허용 범위 |
| 감독 | PC·브라우저·카메라·화면 공유·모바일·신분 확인 요구 |
| 사전 테스트 | 제공 여부·필수 여부·가능 기간·완료 표시 |
| 장애·제출 | 재접속·문제 신고, 자동 저장과 최종 제출 기준 |

“프로그래머스”라는 플랫폼명만으로 Monito+ 설치·모바일 감독·신분증·외부 AI 금지 여부를 확정할 수 없다. 공식 일반 가이드도 시험별 접속 방식·기기·문제 유형이 다르며 해당 시험에 적용되는 안내만 따르라고 명시한다. [공식 응시자 가이드](https://user-guide.grepp.co/en/articles/Accessing-the-Test-Page-5dff571a)

상세 안내를 받으면 `templates/exam-preflight.md`의 빈칸을 채우되 개인 토큰이 붙은 링크는 복사하지 않는다. 실제 시험을 확인하려고 임의의 접속 코드나 시험 시작 버튼을 누르지 않는다.

## 세 가지 체험을 구분

| 구분 | 지금 활용할 목적 | 실전 규칙과의 관계 |
|---|---|---|
| 공개 AI 샘플 | 질문·자료·답 입력에 익숙해지기 | 대회 문항·시간·배점을 확정하지 않음 |
| 초대된 사전 테스트 | 본인 PC·기기·네트워크 점검 | 상세 메일에서 제공·필수 조건 확인 |
| 이 폴더 창작 연습 | 계산·규정·AI 오류 검증 | 자체 시간·질문·점수만 사용 |

공개 AI 체험 FAQ를 10월 14일 다시 확인했다. 체험에는 실전 시간 제한·화상 감독이 없고, PC 환경만 지원한다. 문제당 AI 대화는 10회, 사용 횟수 초기화는 불가하며 별도 결과 리포트도 없다. 이 설정을 실제 대회에 그대로 적용하지 않는다. [공개 AI 체험](https://programmers.co.kr/ai-assessment/preview)

일반 사전 테스트는 기기와 네트워크를 확인하는 과정이다. 운영 여부는 시험마다 다르다. **사전 테스트가 필수인 시험에서는 문제 화면 체험 후 체험 종료 버튼으로 완료해야 한다**고 안내한다. 이것은 공개 AI 샘플의 대화 횟수 초기화와 다른 기능이다. [프로그래머스 사전 테스트 안내](https://user-faq.grepp.co/ko/articles/%EC%82%AC%EC%A0%84-%ED%85%8C%EC%8A%A4%ED%8A%B8%EA%B0%80-%EB%AC%B4%EC%97%87%EC%9D%B8%EA%B0%80%EC%9A%94-ca2e42b8)

일반 최소 사양 표는 최신 Chrome·Edge·Whale, RAM 8GB, 1280×720 해상도, 업로드 최소 1Mbps·권장 5Mbps 등을 제시한다. 이 표는 참고이며 본인 대회 안내와 사전 테스트가 우선이다. 로컬 Python 실행 성공은 카메라·화면 공유·네트워크가 시험에 적합하다는 증거가 아니다. [일반 응시 환경 가이드](https://user-guide.grepp.co/en/articles/Minimum-Requirements-b0a9cc7a)

## 안내를 기다리는 동안 바로 할 연습

연습을 아직 시작하지 않았다면 오늘 첫 수행 기록을 남긴다. 새 자료를 읽는 양보다 직접 풀고 틀린 이유를 확인하는 시간을 확보한다.

1. 공개 체험 목록에서 지식·활용을 확인하고, 본인이 로그인해 체험할 때는 첫 질문 전에 목표와 필요한 자료를 정한다.
2. 기존 기초 퀴즈에서 틀린 주제를 보기 없이 설명한다. 토큰·문맥·환각, 프롬프트·RAG·학습의 차이, 구조와 의미의 차이를 확인한다.
3. 창작 과제 하나를 기준 풀이 없이 끝내고 시간·질문·계산·문서 근거·수정 사항을 기록한다.
4. 개인정보·저작권·출처·권한, 단위·분모·예외·효력일 같은 판단을 체크한다.

공식 예선 안내와 프로그래머스의 공개 평가 목적은 개념과 실제 활용·검증을 함께 준비할 근거가 된다. 별도 제품 구축이나 다중 에이전트 설치를 먼저 끝내야 공부를 시작할 수 있는 것은 아니다. [대회 FAQ](https://skhynix-hackathon.com/ai-2026), [프로그래머스 평가 설명](https://programmers.co.kr/ai-assessment/insight/why-we-built-ai-assessment)

## 공개 검색 결과의 적용 범위

공식 대회·SK하이닉스 채용 사이트·프로그래머스·운영사 관련 도메인을 대상으로 발송 주소, 10월 13일 안내, 1차 예선, 초대·응시 도움말을 검색했다. 검색으로 상세 메일 원본이나 개인별 시간표를 얻지는 못했다. 이것이 실제 안내가 존재하지 않거나 발송되지 않았다는 증거는 아니다.

외부 후기·스터디·대비 서비스에는 특정 문항 수나 형식에 관한 표현이 있다. 공식 공지·개인 안내로 확인되지 않은 숫자를 실전 규칙으로 채택하지 않는다. 다른 지원자의 합격·탈락 사례로 본인의 통과 가능성을 계산하지 않는다. 게시일과 실제 사건일이 맞지 않거나, 아직 열리지 않은 예선 합격을 주장하는 자료도 공식 근거에서 제외한다.

공개 학습 자료는 평가 목적을 이해하고 약점을 보완하는 데 사용한다. 실제 시험의 개별 조건은 운영사의 최신 안내를 받는 즉시 준비에 반영한다.
