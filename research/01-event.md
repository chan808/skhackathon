# SK하이닉스 AI 해커톤 2026 대회 정보와 예선 준비

기준일은 2026년 10월 13일 한국시간이다. 이미 신청을 마쳤으므로 지금의 준비 목표는 **1차 평가 환경 체험, AI 기본 개념 정리, 자료를 읽고 AI 답을 검증하는 연습**이다. 웹개발 경험은 이후 구현 미션에 도움이 되지만, 1차 준비를 새 웹앱 제작에만 집중하면 공개된 평가 범위와 어긋날 수 있다.

## 일정과 참가 조건

| 단계 | 공식 일정 | 방식 |
|---|---|---|
| 접수 | 9월 21일~28일 17시 | 마감 |
| 서류 결과 | 10월 둘째 주 이후 | 문자 안내·지원 내역 확인 |
| 1차 | 10월 17~18일 중 하루 | 온라인, AI 기초 소양·활용 |
| 2차 | 10월 31일~11월 1일 중 하루 | 온라인, 데이터 기반 AI 문제 해결 |
| 본선 | 11월 11일 | 서울 삼성동 코엑스, 현업 난제 |

개인전이며 학력·전공·경력 제한은 없다. 나이는 만 18세 이상 또는 2027년 3월 이내 고교 졸업예정자 기준이다. 군복무·해외거주·외국인도 전 일정 참석이 가능하면 지원할 수 있다. [공식 대회 일정과 FAQ](https://skhynix-hackathon.com/ai-2026)

실제 페이지는 접수 버튼 비활성화·모집 마감 상태다. 정적 검색의 신청 문구를 재접수 가능 신호로 해석하지 않는다. 포트폴리오는 선택 제출, pdf·zip·png·jpg 파일 하나·50MB 이내·URL 불가였다. [공식 지원 FAQ](https://skhynix-hackathon.com/ai-2026)

## 평가 플랫폼의 역할

| 단계 | 공식 문서에 명시된 회사 역할 | 준비에서의 의미 |
|---|---|---|
| 1차 | 그렙: 응시 플랫폼·응시 관리 | 프로그래머스 환경에 먼저 익숙해지기 |
| 2차와 본선 | 크래프톤: 응시 플랫폼·출제·채점 | 데이터·구현·검증 과정 준비 확대 |

위 구분은 대회 개인정보 처리방침 제4조에 직접 나온다. 그렙과 크래프톤에 이름·이메일·전화번호를 제공하고, 두 회사의 보유기간은 본선 종료 후 14일 이내로 명시돼 있다. [공식 개인정보 처리방침](https://skhynix-hackathon.com/my/privacy-policy)

그렙의 공식 계정도 1차가 프로그래머스 AI 역량평가임을 알리고 응시자용 체험을 권한다. 회사 게시물의 공개일은 상대 날짜로만 표시되므로 정확한 게시일은 단정하지 않는다. [그렙 공식 발표](https://kr.linkedin.com/company/grepp/)

SK하이닉스 보도자료는 Cofa-Probe를 포함한 여러 도구로 문제 정의·AI 활용·결과 검증을 살펴본다고 설명한다. 따라서 **1차 전체가 Cofa-Probe라는 해석은 근거가 없다.** 보도자료의 표현과 회사별 운영 역할을 구분해서 읽어야 한다. [SK하이닉스 공식 발표](https://news.skhynix.co.kr/ai-hackathon-2026/), [Talent Hub 동일 발표](https://talent.skhynix.com/hub/ko/company/story/237)

## 1차 준비에 가장 가까운 공개 체험

우선 [프로그래머스 응시 환경 체험](https://programmers.co.kr/ai-assessment/preview)을 열어 지식평가와 활용평가를 확인한다. 공개된 샘플 구성은 다음과 같다. **샘플 문항 수는 SK하이닉스 실제 시험 문항 수를 뜻하지 않는다.**

| 체험 종류 | 공개 샘플 | 형식 |
|---|---|---|
| 지식 | AI 개념·실무 적용 | 10문항, 객·주관식 |
| 활용 | 설문 분석·구독 비용·규정 위반 식별 | 각 4문항, 객·주관식+AI Assist |
| 전문 | 교육 효과 진단·주문 조회 API 오류 | 각 1문항, 서술형+AI Assist |

목록과 FAQ는 공개돼 있지만, 지식평가 시작 버튼은 개인회원 로그인 화면으로 이동했다. 직접 로그인하거나 체험 답안을 제출하지는 않았다. 안내형 화면은 [공식 페이지에 연결된 데모](https://demo.arcade.software/b5dk0zn4GHjoXFKsAmpP?embed=&embed_desktop=inline&embed_mobile=inline&show_copy_link=true)에서도 확인할 수 있다.

체험 FAQ에 따르면 PC 환경만 지원한다. 문제 풀이 환경은 실전과 같지만 체험에는 시간 제한·화상 감독이 없다. 문제당 AI 대화는 10회이며 사용 횟수 초기화는 불가하다. 체험 자체는 반복 가능하지만 결과 리포트는 제공하지 않는다. 체험 모델의 답변 품질은 실제 시험과 다를 수 있다. [공식 체험 FAQ](https://programmers.co.kr/ai-assessment/preview)

첫 체험에서는 점수 추정보다 아래 항목을 기록한다. 제한된 체험 대화를 무작정 소모하지 않도록 먼저 화면과 자료를 읽고, 다음 행동의 목적을 정한 뒤 질문한다.

1. 자료 파일을 읽고 첨부하는 데 걸리는 시간.
2. 질문 전에 스스로 확정할 수 있는 조건과 계산.
3. 답안 입력칸이 요구하는 단위·표현·형식.
4. AI 답에서 확인이 필요한 숫자·규칙·누락 항목.
5. 마지막 답을 고른 근거와 오답 후보를 버린 이유.

### 일반 플랫폼 설명과 이번 시험 규칙 구분

프로그래머스의 10월 7일 설명은 질문 횟수 제한, 30초 쿨타임, 지문 그대로의 복사·붙여넣기 제한, 자료 선택·첨부, 과정과 결과의 평가를 소개한다. 지식·활용·전문평가를 기업별로 조합할 수 있어 문항 수와 시간은 달라진다고 한다. **30초나 10회를 SK하이닉스 실전의 확정 설정으로 옮기면 안 된다.** [프로그래머스 공식 설명](https://programmers.co.kr/ai-assessment/insight/why-we-built-ai-assessment)

이 설명에서 얻을 준비 방향은 질문을 길게 만드는 기술보다, 필요한 정보를 고르고 실행 후 결과를 검증하는 능력이다. 예를 들어 파일 전체를 무조건 넣는 대신 필요한 날짜·대상·기준을 먼저 정하고, AI가 낸 집계값을 표본과 합계로 다시 확인한다. 복사 제한이 보이면 OCR·스크립트 등으로 우회하지 않는다.

## 확인된 규정과 아직 개별 안내가 필요한 부분

예선 FAQ는 반도체 암기보다 AI로 문제를 정의하고 해결하는 과정을 강조한다. 배정 일정 변경은 어렵다. 행위 로그와 AI 검증으로 부정행위를 감시하며, 적발 시 실격과 향후 채용의 영구 제한 가능성을 안내한다. 상금은 총 1억원 규모이고 홈페이지 혜택에는 서류·SKCT 면제가 표시되지만 채용 FAQ에는 서류 면제·면접 기회만 나온다. 세부 적용범위는 개별 안내를 기준으로 확인한다. [공식 예선·채용 FAQ](https://skhynix-hackathon.com/ai-2026)

이용약관 제9·11·13·14조는 대리응시, 응시 중 문제·답안·산출물 공유, 제공 자료의 무단 외부 공개를 금지한다. 산출물 권리는 참가자에게 있고, 운영사에는 심사·기록·홍보·사례소개를 위한 비독점 무료 이용권을 준다. 대회 종료 전 공개를 제한할 수 있다. 권리 침해 등 중대한 위반은 실격·수상취소·상금환수 대상이다. [공식 이용약관](https://skhynix-hackathon.com/my/term-of-service)

공개 페이지에는 아래 실전 설정이 구체적으로 제시되지 않았다. 일반 플랫폼 특징을 시험 허용규칙으로 바꾸지 말고, 받은 안내문에 아래 항목이 있는지 확인한다.

| 확인 항목 | 확인해야 하는 내용 |
|---|---|
| 배정 | 17일·18일 중 본인 날짜, 접속·시작·종료 시각 |
| 구성 | 영역별 문항 수, 총시간, 앞 문항 재방문 가능 여부 |
| AI | 제공 AI 모델, 질문·토큰 제한, 응답 대기 설정 |
| 외부 도구 | 외부 ChatGPT·Codex·검색·IDE·로컬 스크립트·계산기 허용 여부 |
| 감독 | 카메라·마이크·화면 공유, 단일 모니터, 브라우저 조건 |
| 자료 | 메모·교재·사전 코드·프롬프트 템플릿·외부 파일 허용 여부 |
| 장애 | 재접속 절차, 제출 완료 표시, 현장 기술지원 경로 |
| 채점 | 배점·부분점수·동점 처리·합격 기준 |

시험 중 외부 도구로 실제 지문을 옮기거나 타인·다른 에이전트에게 풀이를 맡기는 준비를 기본으로 삼지 않는다. 이 폴더에서의 연습과 실제 응시 환경을 구분하고, 실전에는 안내문에서 허용한 도구만 사용한다. 받은 안내의 개인 식별 정보와 시험 접속 토큰은 공개 저장소에 넣지 않는다.

질문이 남으면 공식 FAQ 문의주소 support@skhynix-hackathon.com으로 운영사에 확인할 수 있다. 개인정보 처리방침은 일반 문의로 info_desk@likelion.net도 안내한다. 이 조사에서는 문의 발송을 하지 않았다. [대회 FAQ](https://skhynix-hackathon.com/ai-2026), [운영 문의 안내](https://skhynix-hackathon.com/my/privacy-policy)

## 본선과 채용 혜택

본선에서는 AI·반도체 전문가가 AI 평가 결과와 해결 과정·산출물을 함께 살펴본다. 본선 진출자 전원에게 인증서를 주며 수상 여부와 무관하다. 당일 AI 트렌드 세미나는 일반인에게도 개방될 예정이고 참관 세부사항은 추후 안내한다. [SK하이닉스 공식 보도자료](https://news.skhynix.co.kr/ai-hackathon-2026/)

수상이나 혜택을 자동 입사 보장으로 해석하지 않는다. 지금은 합격 기준을 추측하기보다, 제출한 결과가 왜 타당한지 설명할 수 있는 기록을 남기는 편이 낫다. 순위별 상금, 수상인원, 구체 배점, 데이터셋, 본선 구현시간 등은 공개 자료만으로 확정할 수 없다.

## 남은 4일에서 5일의 실행 순서

아래는 공개된 평가 목적과 사용자의 웹개발 경험을 바탕으로 한 준비 제안이며 실제 출제 예고가 아니다.

| 날짜 | 가장 먼저 할 일 | 완료 기준 |
|---|---|---|
| 10월 13일 | 받은 안내 확인, 공개 체험 목록·환경 보기, 지식 진단 | 실전 제한 체크리스트와 약점 5개 확보 |
| 10월 14일 | 기본 개념 정리와 자료형 활용 연습 | 정답뿐 아니라 오답 이유도 설명 |
| 10월 15일 | 데이터·조건·단위 검증 집중 | 오류를 찾고 독립 계산으로 반박 |
| 10월 16일 | 허용 환경 점검과 개인 모의연습 | 시작부터 답안 제출까지 흐름 안정화 |
| 배정 전날 | 새 도구 설치보다 환경 고정과 짧은 복습 | 전원·네트워크·로그인·안내 확인 |

시간이 하루 2시간이라면 개념 30분, 활용 60분, 검증·복습 30분으로 배분한다. 하루 4시간이라면 활용 세트를 하나 추가하고 시간 제한을 둔 창작 모의문제를 푼다. 이 시간 배분과 연습 제한은 학습용 제안이며 실제 시험시간·문항 수를 추정한 것이 아니다.

웹개발 경험으로 빠르게 강화할 수 있는 부분은 조건을 명확하게 쓰는 습관, 오류를 재현하는 능력, CSV·JSON·SQL 결과 검증, 요구한 형식으로 답을 만드는 능력이다. 약한 부분은 AI 용어를 단순 암기하는 대신 실제 사례에서 선택 이유를 설명하는 연습으로 보완한다. 반도체 심화와 새 서비스 전체 구축은 1차 이후로 비중을 늘린다.
