# 출국 전에 끝낼 준비

2026년 10월 15일 KST 확인. 현재 Windows x64 PC를 일본에서도 사용한다. 개인 배정 시간과 완료 기록은 Git에서 제외되는 `data/private/travel-plan.md`에 있다. 일반 설치 설명은 [노트북 준비 안내](LAPTOP-PREPARATION.md), 학습은 [최소 AI 지식](MINIMUM-KNOWLEDGE.md)을 사용한다.

**우선순위는 실제 응시 로그인·공식 사전 테스트 → 일본 회선과 VPN 조건 → 오프라인 복구 → 학습이다.** 이 저장소는 표준 라이브러리만으로 동작한다. 퀴즈·CSV·SQLite·검증을 위해 pip 라이브러리나 모델을 받을 필요가 없다. PDF도 이미 저장돼 있다. PDF를 새로 저작하는 경우에만 reportlab·pypdf·한글 글꼴이 별도로 필요하다.

여행 일정은 첫 세션 한 시간 전부터 마지막 세션 종료와 제출 확인까지 **이동하지 않는 고정 장소**를 확보한다. 관광지·기차·카페의 회선 변경을 전제로 계획하지 않는다. 휴대폰이 감독용으로도 요구되면 테더링·감독·충전을 동시에 하는 상태를 검사한다. 숙소 퇴실 시각도 확인한다.

휴대폰 핫스팟을 주 회선으로 쓸 수 있다. 장소가 바뀌지 않는 상태로 충분히 시험하고, 가능하면 이미 검사한 숙소 회선을 예비로 둔다. 같은 휴대폰의 Wi-Fi와 USB 테더링은 무선 구간의 대안일 뿐, 같은 통신사 장애에 대한 독립 예비 회선은 아니다.

## 2. VPN 판단

공식 대회 FAQ는 해외 거주자의 참가 가능성을 안내하지만, 일본 접속·한국 IP·VPN에 관한 개별 시험 설정을 확정하지 않는다. 이번 검색에서 해당 시험의 해외 접속 성공을 검증할 만한 참가자 경험은 찾지 못했다. 공개 준비 글도 허용 도구·감독 조건을 개인 안내에 맡긴다. [대회 FAQ](https://skhynix-hackathon.com/ai-2026), [공개 준비 글](https://aviss.kr/blog/view.php?seq=165).

| 확인된 조건 | 사용할 구성 |
| --- | --- |
| 해외 직접 접속 허용, 한국 IP 불필요 | 일본 회선 직접 접속으로 공식 사전 테스트 |
| 한국 IP 필요, 일반 VPN 허용 | 한국 서버를 고른 데스크톱 VPN + 해당 회선으로 사전 테스트 |
| 지정 VPN·고정 IP·지정 프로필 필요 | 운영자 배포 구성을 사용; 상용 VPN으로 대체하지 않음 |
| 아직 답변 없음 | 직접 접속과 VPN 후보를 준비하되, 실전 허용·접속 가능 판정은 미확정 |

지정 제품이 없으면 예비 후보는 **Proton VPN Windows 앱**으로 정한다. 한국 서버 선택은 공식 안내상 Plus 계정 대상이다. 무료 계정의 자동 서버 선택으로 한국 IP를 준비했다고 판단하지 않는다. 요금 결제·계정 생성은 보관한 설치 파일과 별개다. [한국 서버 안내](https://protonvpn.com/vpn-servers/korea), [Windows 앱](https://protonvpn.com/download-windows).

노트북 전체 트래픽이 필요한 경우 노트북에 데스크톱 앱을 사용한다. 휴대폰 VPN이 테더링한 노트북에도 적용된다고 가정하지 않는다. 브라우저 확장만으로 감독 앱까지 연결된다고 판단하지 않는다. VPN 연결 후 노트북 브라우저에서 접속 위치와 공식 사전 테스트를 확인한다.

VPN 후보는 일반 한국 서버·기본 프로토콜부터 시험한다. Tor·추가 경유·분할 터널링·광고 차단 등의 복잡한 설정은 필요가 입증되기 전 추가하지 않는다. Kill Switch는 연결 실패 시 인터넷을 막을 수 있다. 한국 IP 필수이면 VPN 실패 때 일본 직접 접속으로 돌아가면 안 되고, 직접 접속이 허용되면 운영자의 승인된 복구 순서를 따른다. [Kill Switch 설명](https://protonvpn.com/download-windows).

호텔 로그인 포털은 일반 인터넷 로그인을 마친 뒤 필요한 VPN을 연결한다. 새 VPN 설치와 네트워크 설정은 시험 당일 직전에 시작하지 않는다.

운영자에게 보낼 문의 초안은 개인 계획에 있다. 답변을 받기 전 자동 발송하지 않는다. 공식 문의는 [대회 FAQ](https://skhynix-hackathon.com/ai-2026)의 주소를 사용한다.

## 3. 핫스팟 준비와 실제 측정

1. 한국에서 사용할 노트북과 휴대폰을 직접 연결한다. USB 테더링은 데이터 케이블과 드라이버까지 검사한다. iPhone을 Windows에서 USB로 연결하려면 Apple Devices 또는 iTunes가 필요하다. [Apple 안내](https://support.apple.com/guide/iphone/share-your-internet-connection-iph45447ca6/27/ios/27).
2. 휴대폰의 로밍/eSIM 상품에서 테더링 허용, 고속 데이터 한도, 한도 소진 후 속도를 확인한다. 데이터 전용 eSIM으로 바꿔도 국내 번호의 로그인 인증을 받을 수 있는지 따로 확인한다.
3. 일본의 실제 응시 장소에서 동일한 회선·VPN으로 공식 사전 테스트를 끝낸다. 다운로드 속도뿐 아니라 업로드, 끊김, AI 응답, 저장·재접속, 요구되는 감독 전송을 관찰한다.
4. 데이터 예산은 직접 관찰한다. 업로드 1Mbps를 두 시간 계속 쓰면 약 0.9GB이고 5Mbps면 약 4.5GB다. **전송량 예시이지 이번 시험의 실제 사용량이나 최소 요구량이 아니다.** 실측값에 다른 트래픽과 재접속 여유를 더한다.
5. 핫스팟 Wi-Fi를 Windows 설정의 ‘데이터 통신 연결’로 지정한다. OneDrive·백업·게임 런처·Store·대용량 다운로드도 직접 일시 중지한다. 이 설정은 모든 업데이트를 완전히 막지는 않는다. [Microsoft 안내](https://support.microsoft.com/en-us/windows/experience/connectivity-networking/metered-connections-in-windows).

시험 중 임의로 핫스팟·VPN 서버를 바꾸거나 새로고침하지 않는다. 미리 확인한 장애 안내에 따라 복구하고 저장·제출 상태를 확인한다. 장애 증거를 남길 때도 실제 문제 촬영·외부 공개 범위는 시험 안내를 따른다.

## 4. 인터넷 없이 복원하는 방법

현재 PC에서 활성화 명령 없이 실행한다.

```powershell
.\.venv-study\Scripts\python.exe scripts\verify.py
.\.venv-study\Scripts\python.exe scripts\build_travel_kit.py
```

결과는 Git에서 제외되는 `output/laptop-kit/`에 저장한다. `TRAVEL-START-HERE.txt`가 설치 파일·복원 순서·무결성 검사 명령을 담는다. 공개 학습 ZIP은 개인 일정·초대·계정·로그인·기존 가상환경·설치 파일을 포함하지 않는다. `data/private/`는 별도 비공개 백업으로 보관한다. 공개 ZIP만 클라우드나 USB에 복사하고, 개인 자료는 공개 링크로 공유하지 않는다.

다른 위치에 ZIP을 풀면 지원 Python으로 환경을 새로 만든다.

```powershell
py -3 scripts\study.py --mode check
```

현재 환경은 Codex 번들의 Python 3.12.14에 연결돼 있고 Windows Python 런처에는 별도 설치 Python이 등록돼 있지 않다. `python` PATH도 WindowsApps 별칭이다. 보관한 Python 전체 설치 파일은 Codex 런타임이 없어졌을 때의 복구용이다. 정상 동작하는 현재 환경은 그대로 사용한다. 보관 파일을 실제로 설치한 것과 혼동하지 않는다.

기본 학습에는 Git도 필요하지 않다. 현재 Git은 Codex 번들에 있으므로 PATH 등록을 전역 수정할 필요가 없다. 인터넷 없이 ZIP 복원이 가능하다. 기존 [커밋 ZIP 스크립트](scripts/build_laptop_kit.py)는 Git·깨끗한 커밋이 필요하고, 새 [출국 ZIP 스크립트](scripts/build_travel_kit.py)는 공개 디렉터리의 현재 작업 파일을 담으므로 이번 미커밋 준비도 포함한다.

프로젝트 스킬의 원본은 [hackathon-preflight](templates/project-skills/hackathon-preflight/SKILL.md)다. [설치 스크립트](scripts/install-project-skill.ps1)가 `.agents/skills/hackathon-preflight/`에 복사한다. ZIP에는 그 위치도 포함된다. Codex에서 `$hackathon-preflight`로 호출하고, 목록에 보이지 않으면 프로젝트를 다시 연다. 스킬 지침 파일은 오프라인으로 보관되지만 Codex 모델 사용은 온라인 연결이 필요하다. [공식 스킬 문서](https://learn.chatgpt.com/docs/build-skills).

## 5. 당일 완료 기준

**현재 로컬 점검 통과 + 본인 공식 체험·사전 테스트 + 일본 현지 회선 점검 + 운영자 조건 확인**이 모두 있어야 응시 환경 준비 완료다. 카메라·마이크·메모리·화면 배율·감독 앱·로그인·국외 접속은 파일과 코드 검사만으로 완료되지 않는다. 개인 [노트북 체크리스트](templates/laptop-checklist.md)에 증거를 기록한다.
