저장소 루트 기준으로 [출국 준비 절차](../../../TRAVEL-RUNBOOK.md)를 읽는다. 개인 일정이나 최신 운영자 답변이 필요하면 `data/private/travel-plan.md`를 확인하되 비공개 내용을 공개 문서에 옮기지 않는다.

이 프로젝트의 학습은 Python 3.11 이상과 표준 라이브러리만 쓴다. `.venv-study`의 실제 실행 파일로 `scripts/verify.py`를 실행하고 결과를 `reports/local-verification.json`에서 확인한다. 새 위치에서는 설치된 Python으로 `scripts/study.py --mode check`를 실행한다. 이동한 가상환경은 재사용하지 않는다.

준비 상태는 로컬 도구 검사, 본인의 공식 체험·사전 테스트, 실제 일본 회선 검사, 운영자 조건 확인으로 구분한다. 미수행 단계는 그대로 남긴다. 브라우저 설치·HTTP 응답·속도 측정만으로 시험 저장이나 감독 연결을 검증했다고 말하지 않는다.

VPN은 운영자가 지정하면 그 구성을 따르고, 해외 직접 접속이 허용되면 직접 접속부터 시험한다. 한국 IP가 필요하면서 VPN 사용이 허용된 경우에 한국 서버를 선택할 수 있는 데스크톱 앱을 시험한다. 국가 자동 선택이나 무료 플랜을 한국 IP 보장으로 취급하지 않는다. 실제 시험 중 IP 변경·재접속은 확인된 운영자 절차를 따른다.

출국용 묶음은 `scripts/build_travel_kit.py`로 생성한다. `output/laptop-kit/TRAVEL-START-HERE.txt`, ZIP, SHA256 기록과 설치 파일을 확인하고 별도 폴더에 풀어 인터넷 없는 실행을 검증한다. 설치·결제·로그인·업데이트가 실제 수행됐는지와 설치 파일 보관만 했는지를 구분한다.

기존 학습 문서를 활용하고 필요한 준비만 추가한다. 계정 연결·네트워크 설정·시스템 전역 설정은 검증에 필요한 실제 조건이 확인된 뒤 변경한다. 개인 보고서에는 확인 시각, 수행 결과, 남은 항목을 짧게 기록한다.
