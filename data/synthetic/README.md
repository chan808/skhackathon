# 합성 로트 데이터 실습

`lots.csv`는 이 폴더를 위해 직접 만든 교육용 합성 자료다. SK하이닉스의 실제 공정 데이터나 공식 해커톤 문제를 포함하지 않는다. 물리적인 반도체 공정 시뮬레이터도 아니다. 데이터 품질 점검과 수치 검증을 연습하기 위한 간단한 장치다.

## 데이터 사전

| 필드 | 의미 | 점검할 조건 |
| --- | --- | --- |
| lot_id | 로트 식별자 | 중복·충돌 여부 |
| timestamp | 합성 로트 시각 | ISO 날짜 형식 |
| equipment | E1 E2 E3 장비 구분 | 비교 집단 유지 |
| product | A B 제품 구분 | 검사 수량과 불량 비율 차이 |
| tested_dies | 검사 수량 | 양의 정수 |
| good_dies | 양품 수량 | 0 이상 검사 수량 이하 |
| temperature | 온도 수치 | 유한한 수치 |
| temperature_unit | C 또는 F | 섭씨로 통일 |

총 245행에는 동일 레코드 중복, 결측 양품 수, 검사 수량 범위 오류, 날짜 오류, 화씨 단위가 들어 있다. 기본 로트 240개와 중복 5개를 구별해야 한다. 결측 양품 수를 0으로 임의 대체하면 수율이 왜곡된다.

## 45분 과제

1. 5분 안에 분석 목표와 데이터 품질 규칙을 적는다.
2. 10분 안에 중복·결측·범위·단위 오류를 찾는다. 동일 ID에 내용이 다르면 임의 선택하지 말고 오류로 처리한다.
3. 10분 안에 전체 수율을 계산한다. `SUM(good_dies) / SUM(tested_dies)`와 로트 수율의 단순 평균을 비교한다.
4. 10분 안에 장비·제품·기간별로 비교한다. 제품 구성이나 검사 수량 차이가 결과를 설명할 수 있는지 확인한다.
5. 10분 안에 발견 사실 3개와 아직 확인할 수 없는 원인 2개를 작성한다. 실험 또는 추가 데이터가 필요한 부분을 표시한다.

첫 시도에서는 `practice/core.py`와 `reports/lab-result.json`을 보지 않고 풀어본다. 완료 후 기준 풀이를 실행해 비교한다.

```powershell
.\.venv-study\Scripts\python.exe -m practice lab
```

기준 풀이의 정제 정책은 오류가 있는 레코드를 제외하고 정확히 일치하는 중복만 제거한다. 실제 공정에서는 제외 자체가 편향을 만들 수 있으므로 원인과 영향을 검토해야 한다. 이 과제의 정제 정책을 실제 공정에 그대로 적용하지 않는다.

## 검증 기준

원시 행 수는 정제 행 수와 제외 행 수의 합과 같아야 한다. Python 계산과 SQLite 계산은 일치해야 한다. 수율은 0부터 1 사이여야 한다. 그룹별 양품 합계와 검사 합계는 전체 합계와 같아야 한다. 화씨 158도는 섭씨 70도로 변환해야 한다.

데이터는 시드 `20261013`으로 재현된다. 데이터에 직접 주입한 장비별 패턴은 학습 장치이며, 분석으로 실제 장비 결함의 인과관계를 입증한 결과가 아니다.
